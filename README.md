# Liftlog
Контроль тренувань

Особистий щоденник тренувань: план і факт підходів, тоннаж та прогрес.

## Запуск
Відкрийте `index.html` у браузері або запустіть статичний сервер із цієї папки:

```sh
python3 -m http.server 8000
```

Після цього відкрийте http://localhost:8000. Збірка та встановлення пакетів не потрібні.

## Можливості
- Спина + біцепс; груди + трицепс.
- Власна бібліотека вправ і заміна вправ у тренуванні.
- Планова й фактична вага та повтори для кожного підходу.
- Тоннаж виконаних підходів: сума ваги × повторів.
- Історія та графік тоннажу окремо за типом тренування.
- Цикл: 6 тижнів наростання та 1 полегшений.

## Стан прототипу
Вправи та ваги прикладові. Прогресія +2,5% на тиждень і 60% базової ваги на сьомому тижні — початкова схема для погодження, не остаточна програма. План редагується вручну. Кнопка «Нове тренування» створює окремий запис навіть у тому самому тижні. План переноситься, факт заповнюється з плану, відмітки виконання скидаються. Виконаний попередній результат зберігається в історії. Повторне завершення поточного тренування оновлює лише його запис.

Дані зберігаються тільки в localStorage поточного браузера, ключ `liftlog-v1`. Серверної бази, входу та синхронізації між пристроями немає. Зміна адреси або браузера не переносить старі дані автоматично. Не очищуйте сховище браузера, якщо потрібна історія.

## Структура
- `index.html` — розмітка.
- `style.css` — адаптивне оформлення із системними шрифтами.
- `app.js` — логіка та локальне збереження.
